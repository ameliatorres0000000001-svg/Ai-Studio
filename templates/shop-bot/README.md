# Telegram Shop Bot (generated)

This repo was generated by Claude Code Studio's **Bot Builder**. Everyday changes —
shop name, products, prices, description, payment method — live in
`config/bot.json`. The code in `api/webhook.js` is a tested template; it should
not normally need to change.

## 1. Deploy

Deploy this repo to Vercel (Import Project → this repo). No build step is
needed — Vercel runs `api/webhook.js` as a serverless function automatically.

## 2. Set environment variables

In the Vercel project settings, add:

| Variable | Where to get it |
|---|---|
| `TELEGRAM_BOT_TOKEN` | From `@BotFather` → `/newbot` (or `/token` for an existing bot) |
| `ADMIN_CHAT_ID` | See below |
| `TELEGRAM_WEBHOOK_SECRET` | Recommended. Any long random string you invent (e.g. 32 random letters) — you paste the same value into `setWebhook` in step 3. Without it, anyone who guesses your webhook URL can send fake orders to your admin chat. |

### Finding your admin chat id

1. Send any message to your new bot in Telegram.
2. Visit `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates` in a browser.
3. Find `"chat":{"id":123456789, ...}` in the response — that number is your chat id.

## 3. Point Telegram at your deployment

After deploying, visit this URL once (replace every placeholder, including
`<YOUR_SECRET>` with the `TELEGRAM_WEBHOOK_SECRET` you set above — remove
`&secret_token=...` only if you chose not to set that variable):

```
https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook?url=https://<your-deployment>.vercel.app/api/webhook&secret_token=<YOUR_SECRET>
```

You should see `{"ok":true,"result":true,...}`.

If your bot suddenly stops responding after adding the secret, re-run the URL —
Telegram only sends the secret header for the value registered at the most
recent `setWebhook` call.

## 4. Test it

Message your bot `/start` in Telegram. It should show your product list. Tap a
product, tap "Order", reply with your name/phone/address, and (if
`ADMIN_CHAT_ID` is set) you'll get a notification.

## Editing products later

Edit the `products` array in `config/bot.json` and redeploy — no coding
required. Each product is:

```json
{ "name": "...", "price": 5, "currency": "USD", "description": "..." }
```

## Payment methods

Set `payment.method` in `config/bot.json` to one of:
- `"manual"` — the bot tells customers the seller will contact them to confirm payment.
- `"external_link"` — set `payment.details` to an ABA PayWay / Wing / Bakong KHQR
  link; the bot sends it to customers after they order.
- `"telegram_invoice"` — requires a payment provider token from
  `@BotFather` → your bot → **Payments**. This template tells customers an
  invoice is coming; wiring up `sendInvoice` is a follow-up step, since
  provider coverage for KHR/local gateways varies.
