# Telegram FAQ Bot (generated)

This repo was generated by CodingStudio's **Bot Builder**. Everyday changes —
bot name, questions and answers, contact username — live in `config/faq.json`.
The code in `api/webhook.js` is a tested template; it should not normally need
to change.

## 1. Deploy

Deploy this repo to Vercel (Import Project → this repo). No build step is
needed — Vercel runs `api/webhook.js` as a serverless function automatically.

## 2. Set environment variables

In the Vercel project settings, add:

| Variable | Where to get it |
|---|---|
| `TELEGRAM_BOT_TOKEN` | From `@BotFather` → `/newbot` (or `/token` for an existing bot) |
| `TELEGRAM_WEBHOOK_SECRET` | Recommended. Any long random string you invent — you paste the same value into `setWebhook` in step 3. Without it, anyone who guesses your webhook URL can talk to your bot as if they were Telegram. |

## 3. Point Telegram at your deployment

After deploying, visit this URL once (replace every placeholder):

```
https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook?url=https://<your-deployment>.vercel.app/api/webhook&secret_token=<YOUR_SECRET>
```

You should see `{"ok":true,"result":true,...}`.

## 4. Test it

Message your bot `/start`. It should list your questions as buttons. Tapping one
shows the answer; typing a question that contains one of its `keywords` works too.

## Editing the answers later

Each entry in `config/faq.json` is:

```json
{ "question": "...", "answer": "...", "keywords": ["word", "another"] }
```

`keywords` is what lets a customer type a question instead of tapping a button —
include the words they would actually use, in Khmer and English. You can also
edit this from CodingStudio's Bot Builder page, which commits the change for you
and lets Vercel redeploy automatically.

`config.contact.username` adds a "contact the seller" button; leave it empty to
hide that button.
